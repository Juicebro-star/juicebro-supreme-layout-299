# 给接收技能包的 Agent

当用户把本仓库链接、ZIP或解压目录交给你并要求安装/使用时，按以下信息处理。安装授权只覆盖本技能，不代表授权发布公众号或更改其他工具配置。

1. 从用户给的输入获取整个目录。仓库的入口是根目录SKILL.md；vendor/layout-engine是内部组件和脚本，不需要把内部SKILL.md再装成另一个独立技能。
2. 阅读根目录SKILL.md和README。检查当前Agent支持的技能安装方式及Python环境，不根据另一个客户端的目录结构猜安装位置。
3. 安装整个文件夹。遇到同名版本先比较，按当前用户指令决定更新；未获得覆盖授权时保留旧版并向用户说明差异。
4. 检查目标目录中的组件、预览模板、脚本及文末素材都存在。运行 `python3 scripts/package_article.py --help` 检查辅助脚本入口；Windows按本机环境用python或py -3。
5. 支持技能自动发现时确认已发现本技能；不能自动发现时，明确说明已保存路径，可以直接读取根目录SKILL.md执行，不把它称为已经在客户端注册成功。
6. 无附件读取、联网下载、文件访问或Python执行能力时，只报告具体缺口，不编造安装成功。缺少文章时先完成安装，不擅自给用户另写一篇文章。
